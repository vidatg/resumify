# PortfolioAchievementsComponent

| Property     | Value                          |
|-------------|--------------------------------|
| **Type**    | Feature (Smart)                |
| **Scope**   | Public                         |

## Responsibility

Orchestrates the achievements section (Page 2) by injecting `ResumeDataService` to obtain metrics, achievements text, and accomplishment items, then delegates all rendering to `PortfolioAchievementsUiComponent`.

## Usage

```html
<app-portfolio-achievements />
```
