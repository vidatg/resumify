# SectionHeroComponent

| Property     | Value                          |
|-------------|--------------------------------|
| **Type**    | Feature (Smart)                |
| **Scope**   | Public                         |

## Responsibility

Orchestrates the hero section (Page 1) by injecting `ResumeDataService` to obtain personal information, skills, tools, and AI tools data, then delegates all rendering to `SectionHeroUiComponent`.

## Usage

```html
<app-section-hero />
```
