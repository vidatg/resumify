# SharedSectionHeadingUiComponent

| Property     | Value                          |
|-------------|--------------------------------|
| **Type**    | UI (Presentational)            |
| **Scope**   | Public (Shared)                |

## Responsibility

Renders a styled section heading with an indigo left-border accent. Used as a consistent visual anchor across all resume sections.

## Usage

```html
<app-shared-section-heading-ui title="Core Skills" />
```
