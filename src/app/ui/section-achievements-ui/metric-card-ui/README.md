# MetricCardUiComponent

| Property     | Value                          |
|-------------|--------------------------------|
| **Type**    | UI (Presentational)            |
| **Scope**   | 🔒 Private (nested in `section-achievements-ui`) |

## Responsibility

Renders a single metric stat card with a label and highlighted value. Used exclusively within the achievements section.

## Usage

```html
<app-metric-card-ui [metric]="metric" />
```
